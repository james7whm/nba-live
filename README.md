# NBA 桌面直播条

![应用图标](docs/app-icon.png)

Windows 11 x64 的轻量悬浮文字直播工具。原生 WPF 窗口，默认 360×110 DIP，浅灰便签、置顶、最近两条动态。程序不会播放声音，也不会因为直播更新抢走键盘焦点。

当前版本：**1.0.0 · 首次发布**。包含文字直播、球员技术统计、球星关注、胶囊悬浮和事件回顾。

## 使用

1. 解压 `NbaLive-1.0.0-win-x64.zip` 到任意可写目录，运行其中的 `NbaLive.exe`。整个目录一起保留，无需安装 .NET，也无需管理员权限。
2. 选择当天比赛，单击「查看文字直播」。也可选择其他日期查看文字实录。
3. 鼠标移入直播条，下方出现拖动柄、文字／球员切换、回顾、更多、隐藏，并暂停当前已有比分与内容的显示。选赛、历史、球员统计和设置在「更多」中。后台持续更新，左下角显示悬停后新增条数；移开后回到最新内容。
4. `Ctrl+Alt+H` 隐藏／恢复；隐藏后仍更新。`Ctrl+Alt+L` 开启／关闭鼠标穿透，默认关闭。
5. 开启穿透后，使用快捷键或系统托盘菜单恢复交互。托盘双击可显示／隐藏，右键提供所有操作和「退出」；右键直播条也可打开相同菜单。托盘图标可能位于 Windows 的折叠区域。

设置支持宽度 280～480 DIP、字号 11～16 DIP、背景不透明度 20%～100%，不会降低文字自身的不透明度。快捷键支持 Ctrl、Alt、Shift 与字母、数字、F1～F24；冲突会在设置中提示。位置按物理屏幕坐标保存，多显示器断开后会限制到可见区域。拖动到角落附近可吸附。

文字显示模式包括：仅比分（58 DIP 高）、比分＋一条动态（84 DIP 高）、比分＋两条动态（默认 110 DIP 高）。修改大小时保留所在角落；位置不便操作时，可从托盘选「回到当前屏幕右下角」。重复启动会显示已运行的窗口，不会创建第二个订阅。

可开启「只看得分、犯规、暂停和节次变化」。这是关键词筛选，可能遗漏或误判；仅影响悬浮条，历史窗口始终保留全部文字。关注球队填写与赛程一致的名称（例如「湖人」），该队比赛会带 ☆ 并排在选赛列表前面，不会自动切场。

配置：`%LocalAppData%\NbaLive\settings.json`。保留外观、位置、快捷键、上次比赛、内容模式和关注球员；不永久保存直播历史或回顾。历史窗口显示本次订阅获取的文字，由早到晚更新，保持阅读位置。切换比赛清空旧场次会话历史。

## 球员技术统计

选择比赛后，点悬浮条「更多 → 球员技术统计／关注球员」或托盘的「球员技术统计」，打开独立阅读窗口。双方球队用页签切换，显示首发／替补、出场时间、得分、篮板、助攻、投篮、三分、罚球、抢断、盖帽、失误、犯规、前后场篮板、正负值和位置，并显示球队合计。

点击列标题排序；球员姓名列固定，窄屏可横向滚动查看其他列。自动更新保留排序、选择和阅读位置，切换当前比赛会清空旧场次数据。未出场球员保留来源说明，缺失数值显示「—」，不会当作 0。

统计窗口打开或启用有关注对象的球员卡时，进行中每 15 秒、赛前每 30 秒获取数据；没有消费者后停止。两种视图共享单个统计订阅；胶囊收起或快捷隐藏不会停止已启用的球员卡取数。比赛结束或取消后停止自动刷新，可点「刷新」手动复查。与文字直播共用同一个请求通道，网络失败按 5／10／20／30 秒退避重试、保留最近成功的数据和更新时间；数据不可用时显示异常状态，可稍后刷新。统计与文字分别采样，比分／时间可能略有差异；统计窗口顶部始终使用该统计快照自身的比分。

## 球星盯梢、胶囊和回顾

- **球员卡**：在统计表点 ☆，可跨球队按顺序关注最多 3 人。悬浮条切换到「关注球员」后显示得分／篮板／助攻，以及出场时间和投篮；悬停可查看其他统计。每 8 秒轮换，悬停暂停，‹／› 可手动切换。未出场和本场没有数据会明确提示，不自动更换关注对象。
- **胶囊**：设置、「更多」或托盘可开启，默认关闭。平时 280×30 DIP、单行比分，悬停 100 毫秒展开为配置宽度×110 DIP，离开 250 毫秒收起。菜单和提示显示时保持展开，临时展开不改写保存的位置。
- **刚才发生了啥**：点击「回顾」或托盘对应入口。首次显示最近 10 条已获取事件，此后整理上次回顾后收到的新增记录；角标为新收事件数，悬停左侧的 +N 则只表示悬停后新增数，两者独立。来源修正不会增加未读数，迟到收到的事件会计入。
- 回顾展示当前比分、与上次回顾的比分前后对照、最多 5 条关键事件摘录和本次范围内的全部原文。采用本地规则，不调用 AI，不推断连续得分、领先变化或因果关系；网络接收时间也不等于事件实际发生时间。
- 回顾生成后保持固定，阅读期间不跳动；可点「查看新增」获取后续内容，也可重看最近 10 条。首次快照成功显示后建立回顾起点，此后只标记实际显示范围已读，生成后到达的事件继续累计；切场或重新选同一比赛会重置回顾，重启后不保留已读进度。

## 数据与状态

读取数据源公开的 NBA 比赛中心与文字直播页面，进行中每 5 秒获取单场快照，赛前通常每 30 秒、预计开赛前 5 分钟起每 10 秒检查；同一数据源最多一个请求在途。比赛结束／取消停止轮询；重启仅自动恢复仍在进行的上次比赛。比赛列表打开时每 60 秒刷新。相同网页跳过重复 HTML 解析，内容无变化时复用历史列表；历史窗口使用虚拟化列表减少控件数量。

状态栏分别显示「连通」和「新事件」：前者是本机最近成功检查页面的时间，后者是本机最近发现新增条目的时间，不是事件实际发生时间。比赛暂停、节间休息没有新文字，不会据此判为断网。悬停状态提示可读详细说明。

优先 HTTPS。部分网络上数据页面的 TLS 握手失败时，只对配置的数据源域名的公开比赛页面回退 HTTP；不发送 Cookie、账号或其他用户数据，也不禁用证书验证。设置底部显示当前传输方式。页面只按文本解析，不执行站点脚本。实际请求端点集中定义在 `src/NbaLive.Core/SourcePages.cs`。

连接中断时保留最后一次成功的比分和文字，并显示最近更新时间；按 5、10、20、30 秒重试。无法识别页面显示「数据源异常」。没有比赛时明确显示空状态。网页结构变更可能需要更新解析器。

应用内不提供外部网页跳转；异常提示提供刷新建议。

**本地取数、静态解析与持续实时更新是不同验收项。请参阅 `docs/VERIFICATION.md` 中的实际验证结果。** 第一版没有账号、视频、评论、多场轮播、自动更新和开机启动。

## 演示预览

命令行运行 `NbaLive.exe --demo`，使用明确标识的虚构数据，每 5 秒添加一条动态；不访问网络，配置与真实模式隔离。正式启动默认不会出现演示数据。真实模式与演示模式各限一个实例；同时运行时可给演示模式设置不同快捷键，避免注册冲突。

开发检查可加 `--settings` 自动打开设置、`--statistics` 自动打开统计、`--recap` 自动打开回顾，或加 `--inspect-overlay` 临时让悬浮窗口显示在任务栏以便可访问性工具定位；这些参数用于首次启动测试进程，默认启动不启用。

## 开发与验证

需要 Windows 11 x64、.NET 10 SDK（`global.json` 固定 10.0.402，可滚动到兼容的较新特性带）。项目内的 SDK 如果存在于 `.tools/dotnet`，脚本优先使用；否则使用 PATH 中的 SDK。

```powershell
dotnet build src/NbaLive/NbaLive.csproj -c Release
dotnet run --project tests -c Release
dotnet run --project tests -c Release -- --probe
dotnet run --project tests -c Release -- --probe-statistics --game 168863
pwsh -File scripts/build.ps1
```

自动测试使用独立控制台测试运行器，失败时退出码为 1；包含真实页面样本、加时、相同时刻多事件、乱序、修正、退避重试、取消和配置恢复。`--probe` 对当天实际网页进行联网解析。

有正在进行的比赛时：

```powershell
pwsh -File scripts/observe-live.ps1 -GameId 168863 -Seconds 1800
```

将编号替换为当天正在进行的比赛。日志记录事件数量、最近事件、状态与比分，仍需与数据源网页人工核对。已结束／未开始的场次返回非零退出码，不会当作直播验证通过。

应用运行后执行一小时资源采样：

```powershell
pwsh -File scripts/measure-resources.ps1 -Seconds 3600
```

采样保存在 `artifacts/resources-*.csv` 和 `.json`。CPU 百分比按整机逻辑处理器归一化，内存目标指进程工作集。资源测试需注明真实比赛、闲置或演示模式，不能互相替代。

## 结构

- `src/NbaLive.Core`：比赛模型、HTML 适配器、订阅状态机与配置。
- `src/NbaLive`：原生窗口、托盘、全局快捷键与 Win32 窗口行为。
- `tests`：可离线运行的场景测试、可选联网探针与观测工具。
- `scripts`：构建压缩包、直播观测与资源采样。

第三方依赖与许可见 `THIRD-PARTY-NOTICES.md`。

应用图标使用自绘的篮球与文字条图形，源文件为 `src/NbaLive/Assets/AppIcon.xaml`。修改后运行 `pwsh -STA -File scripts/build-icons.ps1`，可重新生成多尺寸 ICO 和说明中的预览图。程序文件、窗口及系统托盘共用该图标。

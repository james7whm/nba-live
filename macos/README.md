# NBA 直播条 · macOS 原生开发预览

`macos/` 是与 Windows 版本同仓库、独立构建的 Swift 应用，使用 AppKit 菜单栏与 SwiftUI 控件，不需要 .NET、Avalonia 或 Windows 运行环境。最低运行目标为 macOS 12.0，分别支持 Intel 和 Apple Silicon；当前是开发预览，尚未发布正式版。

## 功能

- 启动后顶部菜单栏显示双方简称和比分；左键打开直播面板，右键显示选赛、统计、历史、回顾、设置与退出。没有 Dock 常驻图标。
- 支持日期选赛、实时比分与节次、主播文字、赛况实录回退、会话历史、按本次查看边界回顾和双主题。悬停直播面板暂停当前展示，离开后恢复，后台继续取数。
- 统计窗口展示双方球员及基础数据、首发与在场标识，可关注最多 3 人；关注球员卡每 8 秒轮换，可手动切换。直播、统计和赛况请求使用同一个请求队列。
- 设置可切换主播／赛况、实时最新／完整补播、文字／关注球员和外观。比赛结束后收取主播尾声；内容仅保留本次会话，个人偏好存放在当前 macOS 用户的应用设置中。
- `⌘⌥H` 隐藏／恢复应用窗口，`⌘⌥L` 切换鼠标穿透。快捷键冲突时设置页会提示，菜单栏右键仍可恢复操作。

本版尚未移植 Windows 的球队与排名、历史赛季、季后赛／附加赛对阵图、球队得分图、球员投篮详情、收藏管理与在线升级；鼠标穿透为菜单栏面板临时状态。数据源无主播时使用公开赛况实录，数据不可用时保留已有内容并提示，绝不自动切换为演示数据。

## 构建与启动

需要一台可运行 Xcode 15 或更新版本的 Mac，安装 Xcode 命令行工具。**构建电脑的系统要求由 Xcode 决定；应用的目标系统是 macOS 12，不需要用户安装 Xcode。**

在仓库或源码包解压后的根目录运行：

```sh
swift test --package-path macos
bash macos/build.sh arm64    # Apple Silicon
bash macos/build.sh x86_64   # Intel
```

脚本在独立 `artifacts/` 目录输出 `.app` ZIP 与 SHA256 文件，检查架构与最低系统版本，加入项目图标、球队 Logo、许可文件及 Swift 运行库。输出名带 `swift-preview-macos12`，不覆盖已有包。脚本采用本机 ad-hoc 签名；公开分发前还需 Apple Developer ID 签名和公证。

解压后把 `NBA Live.app` 放进「应用程序」并打开。首次选择比赛；下次启动时仅恢复今天仍在进行的上次比赛。隐藏／关闭直播面板不停止取数，从菜单栏可以重新打开。

## 数据与验证边界

赛程优先读取移动端的近期日期列表；超出该列表范围或列表服务异常时尝试公开网页赛程，并以双方球队及日期唯一对应原网页赛况。主播 ID、比赛 ID 和球员 ID 均按字符串处理；主播消息按来源分页与前后关系去重，不将数字 ID 当时间排序。某个历史日期无法取得移动端比赛 ID 时，使用该日期的赛况实录；球员统计可能不可用。

公开数据读取不携带账号、Cookie 或凭据。现有公开数据源的移动端赛程和网页兼容通道使用 HTTP，应用只为这两个域名配置网络例外；主播消息使用 HTTPS。网络或解析失败保留最后成功内容并显示状态，不关闭系统证书校验。

`swift test --package-path macos` 覆盖解析、比赛身份、分页与修正、加时和真实归档夹具。仓库内提供手动触发的 Mac 构建工作流；只有在代码推送并执行后才能证明工作流结果。

当前开发电脑是 Windows，**macOS 12 实机启动、SwiftUI／AppKit 编译、菜单栏、快捷键、鼠标穿透、多屏、签名与持续直播尚未验收**。Linux 上的 Swift 核心测试不能替代 Mac 检查，详见[验证记录](VERIFICATION.md)。

# macOS Swift 原生预览验证记录

日期：2026-10-28。当前验证在 Windows 上的 Ubuntu 环境执行，Swift 编译器版本为 5.10.1。所有源代码及构建配置位于本地 Mac 分支，尚未发布。

- Swift Release 模式下，数据层与状态管理共 17 项自动测试通过，另有 2 项联网探测默认跳过。覆盖真实归档网页与球员名单解析、19 位编号、身份拒绝、主播正反向分页、修正、加时、请求优先级、超时取消、首次选赛、切场迟到响应、悬停冻结、补播、回顾边界、关注上限、统计订阅共享和主播连接失败回退。
- 显式联网测试已读取勇士对湖人归档的主播多页消息和赛况实录，首条主播文字与截图中的「比赛开始！！」一致，并验证消息 ID 去重与赛况球队身份。另一场的比分、主播消息和球员统计曾成功读取，但后续主播直播间请求多次在 8 秒内超时；目前不能认定网络稳定或保证实时延迟。
- macOS 菜单栏及窗口源文件通过 Swift 语法解析；Linux 状态管理测试使用兼容替身，不代表真实 Combine、SwiftUI、AppKit 和 Carbon 已通过编译或运行。

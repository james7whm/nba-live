# 球队与排名、历史赛季

本功能从 v1.3.0 起包含在正式发布包中。此前1.2.4系列的球队、历史赛季与对阵图独立预览包保留，正式使用请下载1.3.0或更新版本。

## 打开和浏览

- 比赛选择页标题下的「球队与排名」、技术统计标题中的主客队名称／Logo、托盘菜单均可打开。重复打开激活已有窗口，浏览球队不切换文字直播比赛。
- 普通入口依次采用上次浏览球队、设置中的主队、当前比赛主队、东部榜首；从统计标题打开时定位指定球队。浏览偏好独立保存，不改变设置中的主队。排名中的星标仅说明该队是设置中的主队。
- 左侧切换东部、西部或六赛区，排名和同战绩顺序沿用来源。单击球队查看右侧详情，也可用方向键选择、按 Enter 打开。数字居中，长队名省略并提供完整名称提示。
- 窗口默认 1100×760 DIP、最小 720×560 DIP，并限制在当前工作区。内容宽度低于 1000 DIP 时，排名与详情改为单页切换，详情顶部提供「返回排名」。右侧独立滚动，近期赛程在其下方。
- 应用全局隐藏会一起隐藏此窗口；恢复保留球队选择、阅读位置与最小化状态。

## 显示内容

球队信息包括 Logo、全名、所属东西部与赛区、战绩、两类名次、胜率和主客场战绩。赛季场均突出得分、失分、净胜分、篮板、助攻和投篮命中率，同时提供三分、罚球、失误，以及可展开的前后场篮板、抢断、盖帽和犯规。

近 10 场色块从旧到新排列，悬停查看对手、北京时间、主客场及比分；开季不足 10 场时仅显示实际已核验场次。下方可切换近 5 场／未来 5 场，展示对手 Logo、主客场、时间和赛果。缺失字段使用「—」或明确说明，不补造未发布的赛程和排名。

## 数据与刷新

当前常规赛沿用原有适配器：排名页提供明确赛季及东西部分组；赛区页必须为同一赛季，且球队胜负与排名页一致后才显示对应名次。历史赛季与季后赛使用下述独立范围适配。

全联盟场均表没有独立赛季字段，因此只有全部 30 队的场均得分与带赛季的排名表吻合、且至少两队已出赛时，才接受整张场均表。列标题和列编号同时校验；无法核验时，保留此前同赛季成功内容和旧时间戳，或显示缺失状态。不会拿其他赛季的表填充空缺。

球队赛程使用明确球队 ID 获取，逐条核对 `season`、`competitionStageType=REGULAR`、`leagueType=NBA` 及双方球队身份。比赛 ID 与球队 ID 始终作为字符串；只统计已结束且有有效胜负的比赛。季前赛、其他赛季、未知状态和无结果场次不计入近 10 场。日期按来源的北京时间字符串解析为 UTC+08:00，避免本机时区影响。

窗口可见且未最小化时每 5 分钟检查，也可手动刷新。当前数据以 5 分钟过期，历史成功数据以 24 小时过期；历史临时刷新失败在 5 分钟后重试，手动刷新绕过对应缓存并重读赛季目录。隐藏、最小化或关闭停止本面板请求，恢复后按缓存是否过期刷新。排名与当前全联盟场均共用快照，仅获取当前浏览球队的常规赛赛程与完整技术统计，不预取 30 队详情。切队／切范围取消旧请求，迟到响应不覆盖新选择；缓存键包含赛季、阶段和球队。

协调器最多缓存 8 个范围排名和 32 个范围＋球队详情；历史来源最多缓存 4 个赛季排名／分组、4 个季后赛账本和 8 份球队历史响应。关闭窗口释放协调器。取数复用现有请求通道，直播请求优先。

排名、赛区、场均和赛程各显示最近成功时间。网络失败保留最近内容并标记异常，窗口关闭时释放协调器与缓存。

## 历史赛季与季后赛

顶部提供赛季搜索、常规赛／季后赛和「回到本赛季」。可输入开季年份 `2023`，也支持 `2023-24`／`2023-2024`；方向键、Enter 和 Esc 可操作下拉面板。赛季目录来自实际历史记录，本次最早返回 1996–97；目录存在不代表所有球队、阶段及字段均完整提供，缺失以界面提示为准。首次默认当前常规赛，此后记住上次范围；回到本赛季恢复当前常规赛及对应队名／标识。

全窗口以赛季＋阶段为统一范围，右侧标题重复标明范围。常规赛保留东西部与当季赛区、排名、战绩、胜率和胜差；已结束赛季将未来 5 场替换为全部赛程／最近 5 场。近 10 场只计所选常规赛，旧到新排列。

季后赛左侧展示种子、战绩和晋级进程，支持全部／东部／西部；不生成“季后赛全联盟排名”或胜差。常规赛最终名次与季后赛种子独立，例如 2023–24 湖人常规赛西部第 8、季后赛第 7 种子。右侧突出场数、阶段战绩和进程，随后为季后赛场均与系列赛；轮次页签仅显示已确认存在的系列赛，下方展示 G1、G2 的主客场、北京时间和比分，右侧可独立滚动。

历史排名、分组、阶段日期和赛程使用明确返回所选范围的公开归档通道；球队技术统计从明确球队 ID 下的历史表按赛季行、阶段字段及表头提取。历史赛区从当季目录读取，允许四／六赛区和不同球队数量，战绩不一致时不附加旧名次。改名球队保留来源当时队名，如超音速、新泽西篮网；缺少匹配旧队徽时使用中性占位。同名球队沿用打包标识用于识别，尚未增加完整年代队徽资料库。

历史赛程核对 `requestedSeason` 与每场的赛季、阶段，不能将根级当前年份当作请求结果。附加赛、季前赛以及不计入常规赛的杯赛决赛排除；重复 ID 修正覆盖原记录。季后赛按该季明确起止日期分月读取，达到分页上限时拒绝不完整汇总；系列赛依据来源轮次和对手组织，不根据比分猜测现代七场四胜赛制。

得分、篮板、助攻、命中率等读取所选阶段的统计表。失分与净胜分仅在完整已结束赛果的场数、胜负和得分均校验吻合后汇总；缺失项显示「—」，不拿防守效率或自然语言代替。模块失败只保留相同范围已成功内容与时间；切范围清除不匹配数据。

只有整季季后赛归档成功且没有该队记录时才提示未参加；阶段日期尚未开始时单独提示；请求失败或整季资料缺失不推断为未参赛。赛季目录临时故障时保留本次会话已确认的历史选项。全局隐藏／最小化关闭赛季下拉，恢复保留范围与阅读位置。

## 安装与打开

在线安装包按提示安装；ZIP需完整解压后运行 **NbaLive.exe**。从选赛页、统计标题球队名称／Logo或托盘打开「球队与排名」。正式配置位于 `%LocalAppData%\NbaLive`，旧开发预览的临时配置不会覆盖正式设置。

- 现代自包含包：`NbaLive-1.3.0-win-x64.zip`，Win10／Win11 x64，无需额外安装运行环境；另有在线安装版与现代轻量ZIP。
- 兼容预览包：`NbaLive-1.3.0-compatibility-preview-net48-win-x64.zip`，Win7 SP1／Win10／Win11 x64，需要 .NET Framework 4.8 或兼容的后续 4.x 环境；Win7／Win10 实机仍待检查。
- 需要离线看布局时，运行 `NbaLive.exe --demo --teams`，面板明确标为演示数据。README 单独标注的历史赛季截图为真实归档，其余界面图仍使用演示数据。

离线测试：`dotnet run --project tests -c Release`；当前取数探针：`--probe-teams`；历史核验：`--probe-team-seasons --season 2023-2024`。WPF 支持 `--teams-only` 与 `--real-team-seasons`，后者实际联网检查历史资料。完整范围及验收限制见 [验证记录](VERIFICATION.md)。

跨赛季对比、完整年代队徽库、高级效率推算和实时排名预测暂未加入。

## 季后赛对阵图

选择季后赛后，顶部增加「球队列表／对阵图」。首次升级仍显示列表；此后独立保存图／表偏好，常规赛始终使用列表。对阵图独占内容区，暖白与炭灰沿用应用主题。默认全景以西左东右向中央总决赛汇聚；内容宽度不足 1000 DIP 自动显示选中球队所在分区，也可切换东部、西部或总决赛。保留可读字号，不挤成微小全景。布局不足时允许滚动。

每张卡片展示双方 Logo、队名、首轮种子和系列赛胜场；不是单场得分。已确认晋级者加粗，另一方弱化但可读。历史旧标识缺失沿用中性占位。定位主队只高亮该季实际参与的系列赛和已确认路径；没有该队记录时说明，不自动改选球队或主队设置。

点击对阵在底部展开详情，不覆盖图形。标题显示双方标识、系列赛大比分、轮次与状态；G1 等卡片统一遵循标题的球队顺序，不随主客场颠倒。点击某场显示北京时间和主客场。双方统计按钮返回同赛季、同阶段的球队详情，正在订阅的直播比赛不受影响。Tab 可聚焦卡片，方向键移动、Enter 展开、Esc 收起。刷新和全局隐藏恢复保留节点、所选比赛及滚动位置；切换赛季／阶段清除旧范围选择。

对阵图由已经取得的全季季后赛账本构建，不新增网络通道或预取球队详情。展示图形时暂停所选球队详情请求，返回列表按已有缓存规则恢复；窗口隐藏／最小化继续暂停整个球队面板请求。相同比赛 ID 的双方记录合并，修正覆盖，队伍／比分／轮次不一致时拒绝生成已核验图形。连线需有下一轮实际共同参赛球队，且上轮比赛已结束、时间顺序成立；歧义和缺失关系提示待确认。没有硬编码所有年代均需四胜，未知轮次另列，不猜测赛制或轮空位置。完整历史归档的冠军还须与排名进程及总决赛结果一致。

本次核验为 2023–24 的 82 场、15 个系列赛和 14 条晋级连线；其他年份随来源资料显示，不表示已逐年人工确认全部历史赛制。无数据、尚未开始、部分记录和刷新失败分别提示，失败保留同范围最近成功图形。原始设计和实现说明见 [对阵图设计](designs/playoff-bracket.md)。

## 附加赛

赛季旁增加独立「附加赛」阶段，默认显示全景对阵，也可查看球队列表。支持2019–20特殊两队规则、之后的四队路径和明确的未举办状态；卡片显示常规赛位次，右侧单独显示最终出线种子。点击比赛查看分节、球队对比和完整球员表，点出线席位定位该季季后赛首轮。附加赛不计入其他两个阶段的战绩和场均。数据范围、历史球员身份边界和使用方式见 [附加赛说明](PLAY-IN.md)。

# NBA 直播条 v1.3.0

本次功能小版本加入球队与排名、历史赛季、季后赛对阵图和附加赛单场数据，沿用暖白／炭灰双主题及现有直播体验。

## 新增与改进

- **球队与排名**：独立窗口展示东西部、赛区、球队战绩、场均、近期赛果和赛程；可从选赛页、统计标题的球队名称／Logo或托盘打开，浏览不切换文字直播比赛。
- **历史赛季**：支持赛季搜索与常规赛／附加赛／季后赛切换，保留当季球队身份，明确区分缺失、未参赛和尚未开始。历史统计不与其他阶段混用。
- **季后赛对阵图**：全景与分区、总决赛视图，Logo、种子、大比分及实际晋级路线；可定位主队，展开系列赛查看逐场赛果和北京时间。
- **附加赛**：独立展示出线路线、单场比分及确认的第7／8种子，点击席位可定位季后赛首轮；2019–20特殊赛制和未触发场次单独处理。
- **附加赛单场数据**：分节、球队对比、双方完整球员表和首发球衣；按明确比赛与球队编号核验，隐藏／收起时暂停请求。球员表刷新保留球队页，历史赛后不显示实时在场红球。
- **操作与布局**：赛季下拉箭头改为居中矢量图形，修正加载中先显示“资料暂不可用”的提示；窄窗口使用单页、单分区或纵向卡片，全局隐藏与恢复保留阅读状态。
- **文档与许可**：补充MIT许可、球队标识权利说明、功能说明和实际双主题截图，README同时提供GitHub与Gitee下载。

## 使用与验证边界

- 打开「球队与排名」，选择赛季及阶段；查看历史示例可选择2023–24。常规赛期间，本季附加赛显示尚未开始。
- 旧正式配置、关注与收藏继续沿用；此前开发预览的临时配置不覆盖正式配置。升级前通过托盘退出旧程序，轻量包不要直接覆盖到完整版目录。
- 现代版与兼容版均覆盖230项核心测试和420项WPF界面检查。已实际抽查2019–20至2025–26附加赛赛果及每季至少一场单场统计，2023–24六场对阵、四个席位和2020特殊布局已进入实际WPF窗口核验。完整记录见仓库`docs/VERIFICATION.md`。
- 历史球员姓名可能只提供原文；尚未验证与实时球员编号的对应，因此归档表不关联实时关注或球员投篮详情。缺失字段显示“—”，不补造数据。
- 历史年份未逐队逐项人工检查；外部服务可能延迟、限流或调整。Win7／Win10实机、多屏系统DPI、长期资源及进行中比赛持续人工对照仍待验收。兼容包继续标为预览。
- 当前主程序和安装器尚无可信代码签名，SmartScreen可能显示“发布者未知”；核对来源与SHA256后自行决定是否运行，无需关闭系统防护。

# NBA 直播条 v1.1.0

本次更新加入主播文字直播、球员与球队统计、质感双主题，并修复展开历史后直播看起来停滞的问题。

## 新功能与体验

- 主播文字解说与赛况实录，可选择实时最新或完整补播；新增分页补齐、去重修正及断网恢复。
- 球员技术统计、统计增量、列预设、双方场上五人及只看关注筛选；最多关注 3 人并轮换展示球员卡。
- 球衣显示号码，首发固定使用球队色；实时在场球员以红色篮球和红字标记。
- 球队分节得分及累计比分走势图，支持加时、时点比分提示和球队配色。
- 默认暖白／可选炭灰双主题、30 支球队 Logo、主题化日历、统一的选赛与统计界面。
- 聊天气泡与篮球图标，保留胶囊、快捷隐藏、鼠标穿透、事件回顾、会话历史及精彩收藏。

## 修复

- 展开历史持续接收消息，阅读旧内容时保持滚动位置；点击「返回最新」可回到顶部。
- 收起历史立即恢复实时更新，鼠标留在卡片上也不再停留在旧快照；普通悬停暂停仍可在下一次移入时生效。
- 修复主播最新页与历史分页方向、批量事件展示、胶囊切换后两行文字与最新快照不一致的问题。
- 修复选赛窗口前置、比赛中比分／节次标记、统计对齐与窄窗口工具栏布局。

## 下载与升级

下载 `NbaLive-1.1.0-win-x64.zip`，解压到新目录并运行 `NbaLive.exe`；整个目录一起保留，无需安装 .NET 或管理员权限。可下载同名 `.zip.sha256` 核对完整性。

原有配置及收藏继续使用 `%LocalAppData%\NbaLive`。先通过旧版托盘退出，再启动新版；无需删除原有配置。旧版 v1.0.0 保留下载。

## 验证与已知限制

- 138 项核心测试及 32 项 WPF 阅读回归通过，Release 构建零警告、零错误；README 包含 24 张标注演示数据的双主题实际渲染截图。
- 数据来自外部服务，仍可能受到发布延迟、HTTP 429 限流或接口变化影响。
- 进行中比赛的 30 分钟 App 对照、一小时资源测量、多显示器与不同系统缩放的完整实机验收尚未完成。
- 当前仅支持 Windows 11 x64；没有自动更新功能。

完整使用说明与验证记录见仓库 README 和 `docs/VERIFICATION.md`。

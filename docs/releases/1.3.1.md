# NBA 直播条 v1.3.1

本次为 Windows 球员单场详情修复版，保留现有配置、关注球员及收藏。

## 修复

- 修复部分球员的网页统计编号与详情编号不同，导致提示“未能唯一对应本场球员编号”的问题。使用已核验的编号映射，并继续校验本场名单、球队及移动端球员编号；不按姓名猜测。
- 修复详情加载失败后，正文仍停留在“正在读取”的问题；手动刷新可正确切换加载、失败与成功状态，已有成功统计在断网时保留。
- 编号映射失败会清除名单缓存并重新获取一次，避免旧名单持续阻止加载；多个候选时拒绝绑定。
- 已结束比赛的确定数据格式／身份异常停止自动重试，保留手动刷新；临时网络失败和进行中比赛继续按原规则恢复。

已核对勇士134:114掘金比赛中伦德博格的31分、12篮板、6助攻、投篮9/19，分节合计及19次出手、9次命中一致。Win7／Win10实机、长时间实况及多显示器验收仍待完成。

现代版与兼容版核心测试各238项、双主题界面回归各428项通过，发行同步检查6项通过。

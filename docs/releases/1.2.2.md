# NBA 直播条 v1.2.2

本次更新加入球员单场详情、更新提醒与一键升级，并优化更新窗口布局。

## 新增与改进

- 单击统计表中的球员行，或选中后按 Enter，在右侧查看头像、全场／分节及加时统计、投篮落点、命中率与出手方式。暖白／炭灰双主题，窄窗口可返回列表；关注、筛选和排序继续使用原有操作。
- 投篮图使用真实单场落点，命中为橙色实心点、未中为空心点；两分按有效总投篮减三分计算。来源缺失的字段显示「—」，不使用赛季热图或文字推算单场数据。
- 设置及托盘提供更新入口，默认启动 30 秒后检查、此后每 24 小时检查。国内优先 Gitee，镜像滞后或不可用时尝试 GitHub；支持关闭自动检查、跳过版本和手动检查。
- 点击「下载并更新」后才下载，校验 ZIP 与逐文件摘要，准备备份后退出并重启；新版启动失败时恢复旧版。配置、关注和收藏保留，未收藏的会话历史随重启清空。
- 更新窗口增加间距并区分主要操作与手动下载入口；没有新版时仅显示「关闭」「检查更新」，有新版才展示升级和跳过操作，支持双主题与 420 DIP 窄窗口。
- README 增加 GitHub 与 Gitee 双下载入口。Gitee 代码镜像不包含发行附件，国内包需单独补齐。

## 下载与升级

| 附件 | 适用系统 |
| --- | --- |
| `NbaLive-1.2.2-win-x64.zip` | Win10／Win11 x64；自包含，无需安装 .NET |
| `NbaLive-1.2.2-compatibility-preview-net48-win-x64.zip` | Win7 SP1／Win10／Win11 x64 兼容预览；需预装 .NET Framework 4.8 或兼容的后续 4.x 运行环境 |

两个 ZIP 各附同名 `.sha256`。v1.2.1 及更早版本需先从托盘退出，解压新版到独立目录，运行 `NbaLive.exe` 完成首次手动升级；此后可在应用内检查后续新版。保留整个解压目录，勿遗漏 `NbaLive.package.json`、DLL 或兼容版配置文件。

[GitHub 发行列表](https://github.com/james7whm/nba-live/releases) · [Gitee 国内发行列表](https://gitee.com/james7whm/nba-live/releases)。本次附件先发布于 GitHub；Gitee 若暂无 v1.2.2，请等待国内附件补齐。旧版发行包继续保留。

## 验证与已知限制

- Win11 上，两套运行时分别通过 167 项核心测试、178 项 WPF 界面回归，覆盖球员详情、直播阅读、布局、全窗口隐藏恢复与更新交互。
- 真实归档核对唐斯 22 分／10 篮板／3 助攻、投篮 9/13、三分 2/3、两分 7/10，以及 13 个落点中 9 个命中；分节得分合计吻合。来源未提供的逐球时间／方式不补造。
- 更新流程已在独立目录验证成功启动、失败回滚及中断恢复；采用固定来源、HTTPS、SHA256 和逐文件摘要，尚未接入独立发布者签名。更新备份保留在本机，确认稳定后可按应用更新文档清理。
- Win7／Win10 实机、进行中比赛 30 分钟人工对照、一小时资源测量及多显示器缩放仍待验收，兼容包继续标为预览。外部接口变化、延迟或限流可能影响数据。

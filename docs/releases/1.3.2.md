# NBA 直播条 v1.3.2

本次更新改善比赛数据读取与球队比分图，保留现有配置、关注与收藏。

- 比赛列表和比分优先使用移动端数据，改善网页赛程不更新或缺失导致的选赛异常；旧比赛编号仍保留兼容。
- 球员统计优先使用移动端；无法可靠对应旧球员编号时回退原网页数据，避免错误匹配。
- 修复部分比赛分节得分及走势图为空、缺节或错位的问题；按比赛时间处理补录事件，并标明独立采样可能造成的短暂比分差异。
- 仅有移动端比赛编号且缺少结构化逐球记录的场次，赛况实录暂不可用；主播文字直播保持可用。

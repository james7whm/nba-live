# NBA 直播条 v1.2.0

本次修复选赛比分截断和直播卡片箭头对齐，并新增面向 Windows 7 SP1 的独立兼容预览包。

## 修复与兼容

- 选择比赛时，双方都是三位数的比分也能完整显示，保留进行中红色比分和赛后胜方加粗。
- 直播卡片展开／收起改用矢量箭头，与节次或「已结束」标签垂直居中；兼顾窄窗口、较大字号及暖白／炭灰主题。
- 同一源码新增 .NET Framework 4.8 构建，适配旧系统 DPI、托盘、单实例通信、日期及配置保存和 TLS 1.2；证书验证保持开启。

## 下载与升级

| 附件 | 使用方式 |
| --- | --- |
| `NbaLive-1.2.0-win-x64.zip` | Win10／Win11 x64 优先选择；自包含，无需安装 .NET |
| `NbaLive-1.2.0-compatibility-preview-net48-win-x64.zip` | 兼容预览，目标为 Win7 SP1／Win10／Win11 x64；需预装 .NET Framework 4.8 或兼容的后续 4.x 运行环境 |

两个 ZIP 均附同名 `.sha256` 校验文件。解压到新目录，保留整个目录及全部依赖，通过旧版托盘退出后再运行新版 `NbaLive.exe`。现代版与兼容版共用 `%LocalAppData%\NbaLive` 配置和收藏；无需删除原有配置。

Win7 必须安装 SP1，运行环境的安装或系统更新可能需要管理员权限。应用自身按普通用户运行；兼容包中的 DLL 和 `NbaLive.exe.config` 必须保留。Win8 和 32 位系统不在本次范围。v1.0.0、v1.1.0 继续保留下载。

## 验证与已知限制

- 在 Win11 上，两套运行时分别通过 138 项核心测试和 68 项真实 WPF 阅读／布局检查，Release 构建零警告、零错误。
- 布局检查包含 114:110、199:188、999:999，280／360／480 DIP 宽度、11／16 DIP 字号和双主题；原历史阅读、胶囊切换与恢复最新继续回归。
- 兼容版已完成当前 Win11 主机上的实际 App 启动流程和 HTTPS 赛程读取；**Win7／Win10 实机或虚拟机测试仍待完成，因此兼容包标为预览版**。
- 数据源延迟、限流及接口变化仍可能影响直播。进行中比赛 30 分钟 App 对照、一小时资源测量、多显示器与缩放实机验收仍待完成。

# NBA 直播条 v1.2.1

本次小版本更新修复日期下拉箭头对齐和隐藏后辅助窗口仍显示的问题，并让关注球队可以直接选择。

## 修复与改进

- 日期选择按钮改用居中的矢量箭头，展开／收起方向正确显示，避免字体基线导致偏移。
- 直播条「隐藏」、`Ctrl+Alt+H` 和托盘显示／隐藏统一作用于全部应用窗口，包括选赛、统计、设置、历史、回顾与收藏；隐藏时关闭日历和下拉菜单。
- 恢复此前可见的窗口与最小化状态，已关闭的窗口不重新打开；隐藏期间继续获取直播，异步选赛完成不会意外显示窗口。从托盘选择具体页面可恢复应用并前置该页面。
- 「关注球队」改为带 Logo 的下拉选择，包含 30 支球队和「不设置」，无需手动输入；保存后仅影响选赛排序，不自动切场。
- 兼容旧球队配置：已识别的简称／全名／英文缩写自动对应球队，未识别旧值保留为「原有设置」。Logo 内置，沿用双主题，无需额外联网。

## 下载与升级

| 附件 | 适用系统 |
| --- | --- |
| `NbaLive-1.2.1-win-x64.zip` | Win10／Win11 x64 优先选择；自包含，无需安装 .NET |
| `NbaLive-1.2.1-compatibility-preview-net48-win-x64.zip` | 兼容预览，目标为 Win7 SP1／Win10／Win11 x64；需预装 .NET Framework 4.8 或兼容的后续 4.x 运行环境 |

两个 ZIP 均附同名 `.sha256` 校验文件。通过旧版托盘退出，解压新版到独立目录后运行 `NbaLive.exe`；保留完整目录，兼容版的 DLL 与 `NbaLive.exe.config` 不可遗漏。

原有 `%LocalAppData%\NbaLive` 配置及收藏继续使用。v1.0.0、v1.1.0、v1.2.0 保留下载；Win8 与 32 位系统不在本次范围。

## 验证与已知限制

- 在 Win11 上，两套运行时分别通过 138 项核心测试、124 项真实 WPF 阅读／布局／隐藏恢复检查，以及 66 项球队选择专项检查；Release 构建零警告、零错误。
- 包内程序集已从独立解压目录检查启动，并核对产品版本 1.2.1、文件版本 1.2.1.0、文件内容及 SHA256。
- **Win7／Win10 实机或虚拟机验收仍待完成，因此 net48 包继续标为兼容预览版。** Win7 必须为 SP1；安装 .NET Framework 或系统更新可能需要管理员权限，应用本身按普通用户运行。
- 系统快捷键与托盘鼠标操作、多显示器与缩放、一小时资源测量及进行中比赛 30 分钟 App 对照仍待验收。外部数据延迟、限流和接口变化仍可能影响直播。

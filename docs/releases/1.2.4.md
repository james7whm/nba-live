# NBA 直播条 v1.2.4

本次小版本更新新增在线安装包与现代轻量版，并优化资源占用和双平台发布流程。

## 新增与改进

- 修复安装器及轻量更新器的运行环境检测：按 .NET 官方规则读取 32 位注册表视图中的 x64 安装记录，避免装好组件后仍提示缺失。v1.2.3 已撤回正式推荐，其附件保留，不同版本之间不替换附件。
- 发布构建增加一次性 Windows 构建机上的真实安装、启动与卸载检查，验证环境安装前后检测、轻量更新器判断与用户数据保留。

- **在线安装包（Win10／11 x64）**：安装器自身不依赖 .NET；检测 .NET 10 Desktop Runtime x64，缺少时经用户确认从微软官网下载、校验并打开组件安装器。应用安装到当前用户目录，提供开始菜单入口、可选桌面快捷方式及卸载入口。取消、失败或需要重启时停止安装，不自动重启。
- **现代轻量 ZIP**：不包含运行环境，先安装 .NET 10 Desktop Runtime x64（最低 10.0.13）再解压运行。在线安装版与轻量版共享独立更新通道，避免升级时重新下载自带环境的完整版；新包要求更高组件版本时保留旧版并提示使用在线安装包。
- **体积与内存优化**：完整版仅保留简繁中文及英文运行资源；Logo 按显示尺寸解码，理论像素缓冲减少 75%；阵容控件首次使用时创建，收起历史后释放显示集合，完整历史仍保留。常驻文字模式未测得明确的内存下降，不宣称大幅节省内存。
- **GitHub／Gitee 分别发布**：GitHub 提供全部四种形态；Gitee 只复制在线安装包、轻量 ZIP、Win7 兼容 ZIP 及各自校验文件，不上传自带运行环境的完整版，不清理既有历史发行附件。
- Gitee 同步改用仓库自带脚本：核对标签提交、按明确文件名复制、下载后验证 SHA256，附件完整后才将预览转为正式；失败可手动重试，同名内容不同拒绝覆盖。README 更新双平台下载与组件安装说明。

## 升级与已知限制

- 通过托盘退出旧程序后运行在线安装器，配置、关注和收藏继续沿用；旧版未收藏的会话历史不跨重启保存。不要将轻量 ZIP 直接覆盖到完整版目录；不想切换形态时可继续使用原有一键更新。
- 两套运行时分别通过 169 项核心测试、190 项 WPF 界面回归，覆盖历史收展、胶囊、阵容延迟创建、Logo 和更新类型；发行同步脚本通过 6 项测试，覆盖白名单、校验失败、失败不发布及保护已有正式附件。
- 安装器及主程序尚未接入可信代码签名，仍可能显示 SmartScreen「发布者未知」，改为安装包不会自动消除提示。
- Win7／Win10 实机、无运行环境电脑上的完整下载与管理员授权流程、进行中比赛 30 分钟对照、一小时资源及多显示器缩放仍待验收；Win7 包继续标为兼容预览。

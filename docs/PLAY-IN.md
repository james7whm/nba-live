# 附加赛：对阵、赛果与单场统计

本功能从v1.3.0起包含在正式发布包中，此前的1.2.4独立预览包保留。

## 如何使用

在「球队与排名」选择赛季，再选择「附加赛」。首次默认对阵图，图／表偏好独立保存，不改变常规赛、季后赛的视图偏好。浏览附加赛不改变当前文字直播比赛。

全景上西下东：7–8位赛的胜者取得第7种子，负者与9–10位赛胜者争夺第8种子；右侧为确认出线球队与实际季后赛首轮对手。卡片的位次为常规赛最终位次，得分为本场比分；出线种子单独标明。点击出线席位可切到同赛季季后赛，并定位实际首轮系列赛。

点击比赛在下方打开概览，展示分节、双方核心统计和代表球员。球队对比提供篮板、助攻、抢断、盖帽、失误、犯规、投篮／三分／罚球等完整指标；命中率由对应命中和出手计算，未出手显示「—」。比分顺序始终与标题一致，日期统一北京时间。

选择「球员数据」或「完整单场统计」会使用整个内容区显示双方球员表，点击「收起」返回此前对阵视图。表格复用原有球衣、列排序、横向滚动和球队合计；球衣颜色表示本场首发，赛后不显示实时在场红球或红字。球员名字与号码沿用本场归档；部分名字只有原文。归档球员编号使用独立身份，目前没有可靠的跨来源编号对应，因此不提供实时关注或球员分节／投篮详情入口，避免关联错误球员。

球队合计可能含球队级失误，不能强行等同于球员逐项求和。球员时间按来源提供的分钟精度显示，不补造秒数。

球队列表展示常规位次、附加赛战绩、已结束场数与最终／当前结果；点球队查看该阶段赛程，点赛程可回到对应单场。得分、失分、净胜分由核验过的本阶段赛果汇总；其他场均需已取得该队全部单场统计，缺失时显示「—」。查看该队所有单场数据后，可刷新球队列表更新汇总。投篮场均命中率按总命中／总出手计算，不平均各场百分比。

## 历史赛制和数据状态

- 2019–20 使用两队规则：第8位球队赢1场即可，第9位球队需2胜。开拓者首场126:122取胜后，后续场次标为「条件未触发」，不记为0:0或生成假比赛。东部未举办状态还需当季位次与胜场差交叉确认。
- 2020–21及之后使用四队路径。9–10位赛胜者即使后来取得第8种子，早先那一场仍显示「进入第8种子争夺」，不会回填为直接晋级。
- 确认未设置附加赛的早年显示明确说明；与尚未开始、资料缺失、刷新失败分开。空数组不会自动等同于未举办。
- 切赛季或比赛立即清除不匹配详情并取消旧请求；失败保留同范围最近成功快照。加载和重试期间显示读取提示。

## 刷新、缓存和布局

本面板沿用球队窗口每5分钟检查的节奏，只有可见且未最小化时工作。单场统计仅为当前展开比赛获取；隐藏、最小化、收起详情、返回列表或切范围都会暂停／取消相应请求。关闭释放协调器，不影响主直播原有更新规则。

附加赛账本最多缓存4个赛季，单场统计缓存最多12场。当前数据按5分钟、已结束归档按24小时复用；手动刷新可以重新读取。取数共用已有 HTTP 请求通道，直播优先，不一次预取六场完整统计。

宽窗口支持全景，内容宽度不足1000 DIP自动显示单分区和纵向卡片；可切东／西部，字号保持可读，内容不足时滚动。概览在窄窗口改为单列，球员表保留独立滚动。Tab可聚焦对阵，方向键移动、Enter展开、Esc收起；隐藏恢复和刷新保留比赛、球员球队页与阅读位置。

## 数据核验与边界

赛果与统计按明确赛季、阶段、比赛ID和球队ID对应。比赛双方的重复记录合并，修正覆盖原身份；比分、主客场、日期或角色矛盾时拒绝未经核验的新图形。所有ID保存为字符串；附加赛使用独立阶段，不混入常规赛或季后赛场数、战绩和场均。

2023年归档阶段日历与逐场记录存在一天偏差。读取时保留最多前后两天的日历容差，并继续逐场核对明确的赛季、附加赛阶段、参赛球队与角色；范围外数据仍拒绝。不根据季后赛结果反推附加赛赛果。

已实际抽查2019–20到2025–26：2020年1场，随后六个赛季各6场，并分别确认出线席位及至少一场完整单场统计。2023–24全部六场、四个出线种子、鹈鹕对国王105:98和双方球员数据已实际进入WPF窗口。其他比赛、未来赛季及服务长期可用性不作保证；缺失字段如实显示。

## 下载与运行

- `NbaLive-1.3.0-win-x64.zip`：现代自包含包，Win10／11 x64，另有在线安装包和现代轻量ZIP。
- `NbaLive-1.3.0-compatibility-preview-net48-win-x64.zip`：兼容预览包，需 .NET Framework 4.8，目标 Win7 SP1／Win10／Win11 x64；Win7／Win10实机尚未完成。

通过托盘退出旧程序后安装，或将ZIP解压到独立目录运行 **NbaLive.exe**。正式配置位于 `%LocalAppData%\NbaLive`。打开「球队与排名」，选择2023–24和「附加赛」可查看本说明中的历史例子；当前常规赛期间，切到本季附加赛会显示尚未开始。

完整验证和限制见 [验证记录](VERIFICATION.md)，初始确认方案保留在 [附加赛设计](designs/play-in.md)。

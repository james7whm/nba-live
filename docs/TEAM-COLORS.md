# 球队球衣配色

以 [NBA 官方球队页的队徽](https://www.nba.com/teams) 作为配色参考，本表是应用内的固定配色，不是官方品牌色规范。为满足每队色号不同，步行者与森林狼的近似深蓝、76人与勇士的近似蓝色作了轻微 RGB 调整；马刺与篮网使用不同黑色色值。相近色号不保证肉眼能明显区分，球队页签和文字仍用于识别球队。

统计表中球队色球衣表示本场首发，替补为灰色；实时在场由红字和姓名后的红色篮球表示。悬浮「场上五人」视图使用同一球队色表。

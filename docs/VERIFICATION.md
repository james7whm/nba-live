# NBA 直播条 1.0.0 验证记录

首次发布包含文字直播与关注筛选、球员技术统计与变化、球队分节得分与走势、列预设、球星关注、场上五人与首发参考、胶囊悬浮、事件回顾、精彩收藏、会话历史和外观设置。本文件按功能汇总验证结果。

验证平台：Windows 11 x64，系统版本 10.0.26200。

## 构建与发布

- .NET SDK 10.0.402，发布运行时 10.0.13，AngleSharp 1.8.5。
- Release 构建启用将编译警告视为错误；Windows x64 自包含发布，无需安装 .NET 或管理员权限。
- 发布 Windows x64 自包含 ZIP，附带 SHA256 校验文件；独立复核包使用描述性文件名后缀，版本均为首次发布基线 1.0.0。压缩包内的程序、依赖、图标和第三方许可需一起保留。
- 程序文件与窗口使用已确认的聊天气泡／暖橙篮球纹图标；托盘使用深浅任务栏各自的简化透明图形，按系统主题与 DPI 选择，接收主题／DPI 变化及任务栏重建通知，替换成功后释放旧图标句柄。应用及项目使用中性名称，界面无来源品牌或地址，不提供浏览器跳转入口。
- 图标从原生 WPF 矢量资源生成，程序和两套托盘图标各含 16、20、24、32、40、48、64、128、256 共 9 帧；脚本逐帧解码核对尺寸与透明角。实际尺寸对照图核对了 16～48 像素在深浅背景下的气泡轮廓和橙色球纹；Windows 11 当前浅色任务栏配置下，独立演示进程成功创建托盘，设置窗口标题栏显示新图标。未为验证更改用户的系统主题；深色变体以解码与背景对照检查。

# NBA 直播条 1.0.0 验证记录

首次发布包含文字直播、球员技术统计、球星关注、胶囊悬浮、事件回顾、会话历史和外观设置。本文件按功能汇总验证结果。

验证日期：2026-10-21（北京时间）。平台：Windows 11 x64，系统版本 10.0.26200。

## 构建与发布

- .NET SDK 10.0.402，发布运行时 10.0.13，AngleSharp 1.8.5。
- Release 构建启用将编译警告视为错误；Windows x64 自包含发布，无需安装 .NET 或管理员权限。
- 发布文件为 `NbaLive-1.0.0-win-x64.zip`，附带 SHA256 校验文件。压缩包内的程序、依赖、图标和第三方许可需一起保留。
- 程序文件、窗口和托盘共用多尺寸图标。应用及项目使用中性名称，界面无来源品牌或地址，不提供浏览器跳转入口。

## 自动测试

`dotnet run --project tests -c Release`：**44/44 通过**。

覆盖范围：

- 比赛列表和文字页面解析、比赛状态、节次与加时、来源顺序规范化、同一时刻多事件、无来源 ID 的身份识别、修正去重、无效日期及损坏结构。
- 赛前空页面、404 和前瞻跳转，赛前／赛中刷新间隔，断网退避及恢复，比赛结束停止，切场取消与丢弃迟到响应。
- 相同页面缓存、文字与统计共用单请求通道、悬停固定比分与内容、待阅计数、重要事件筛选、关注球队排序、连通与新增时间独立。
- 统计表首发／替补、重排列、加时、未出场、空数值、球队合计、正负值、错场和缺失表格；刷新失败保留数据、手动刷新和取消。
- 配置缺省字段、损坏值恢复、显示密度、快捷键校验、关注上限与顺序、持久化及来源身份；球员卡缺失值和场次隔离。
- 统计窗口与球员卡共享订阅、最后消费者退出后停止、缓存复用和切场取消；球员轮换暂停、隐藏和手动切换。
- 首次及延迟首次回顾、最近 10 条、已读边界与阅读期间新增、重看范围、来源修正、迟到事件、重新订阅重置、断网提示和字面比分快照对照。
- 100%～200% 缩放下的四角定位、尺寸变化、负屏幕坐标、显示器移除后的定位计算，以及展开区域包含原胶囊区域。

## 联网取样

- 比赛列表实际取样包含 3 场已结束比赛，文字记录分别读取到 394、405、412 条。
- 2026-10-22 赛程取样读取到 11 场未开始比赛；168965 场次的文字页跳转前瞻时识别为等待直播，不作为连接错误。
- 对 168863 已结束比赛读取统计，双方各 17 名球员，球队得分 106／100，与同页比分一致。
- 本机部分公开页面 HTTPS 握手失败，限定数据源域名的 HTTP 回退可读取；不发送 Cookie、账号或用户数据，不关闭证书验证，不执行页面脚本。设置显示传输方式。
- 已结束和未开始比赛的读取只证明对应页面可解析，**不代表进行中比赛持续更新已验收**。

## 界面与交互检查

使用独立自包含演示进程和 computer-use 插件检查，演示配置与正式配置隔离。

- 默认 360×110 DIP 文字条、设置、选赛、会话历史、球员统计和回顾窗口可正常显示；程序图标和窗口图标正常加载。
- 280 DIP 宽、16 DIP 字号下检查 58／84／110 DIP 显示密度、球员卡、280×30 DIP 胶囊及展开工具栏；长文字省略，悬停提示提供全文。设置窗口可滚动到保存入口并成功保存。
- 悬停时固定比分、文字和球员统计，后台仍接收新增事件；离开后恢复最新。主客队均可加星，第四人被拒绝，关注顺序跨重启保留，支持自动轮换和手动切换。
- 统计表主客队页签、合计、得分排序、手动及自动刷新后保留排序可用；关闭统计窗口后，已启用的球员卡仍继续刷新。
- 胶囊展开时保存坐标保持原胶囊位置，离开后恢复；菜单与提示显示期间保持展开，未观察到反复展开／收起。
- 回顾显示固定的最近 10 条原文和最多 5 条关键事件；阅读期间只增加查看新增计数，点击后切换范围并显示比分前后对照。
- 会话历史使用回收式虚拟化列表，滚动后收到新事件不跳到末尾；短时检查不能替代长时间交互测试。
- 使用独立快捷键检查隐藏／恢复和快捷键冲突。重复启动同模式时第二个进程退出，由原实例响应显示／设置请求。
- 选赛窗口只保留刷新和查看直播按钮，统计窗口只保留刷新按钮；悬浮条右键弹出的托盘共用菜单无来源网页入口，选择比赛菜单可正常打开选赛窗口。
- 清除测试进程的 `DOTNET_ROOT` 后，自包含包仍能启动。默认悬浮条不显示任务栏按钮；UI 检查通过 `--inspect-overlay` 临时允许工具定位。

## 资源目标与待验收项

当前发布的完整功能组合尚未完成一小时资源测试，不能据此声明无泄漏、平均 CPU 低于 1% 或内存低于 100 MB。资源采样命令见 README；不将其他功能组合的短时采样作为本发布包的性能结论。

以下项目仍待验收：

- 进行中比赛连续 30 分钟，与数据页面核对新增文字、顺序、比分、球员统计和延迟。
- 目标电脑连续运行一小时，分别记录文字模式、球员卡和统计窗口的 CPU、工作集及稳定性。
- 多显示器断开／重新连接，以及 125%、150%、200% 缩放切换的实机检查；当前界面实测为 100% 缩放，其他比例仅完成定位计算测试。
- 鼠标穿透后的实际点击落点、托盘图标点击与退出，以及穿透期间通过托盘恢复操作。
- 在其他工作应用持续输入时，核对直播刷新、显示恢复及胶囊展开均不抢焦点；代码已配置对应原生窗口标志。

正式数据不可用时保留最后成功内容并显示异常状态，不会静默切换为演示数据。本次会话的历史和回顾不保存为长期档案。
